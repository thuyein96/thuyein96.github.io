## My Personal Portfolio

This repository hosts the source code for my personal portfolio website. It showcases my projects, skills, and experience as a developer.

### Technologies Used

  * **HTML5:** For the basic structure and content of the website.
  * **CSS3:** For styling and layout.
  * **JavaScript:** For interactivity and dynamic elements.
  * **GitHub Pages:** For hosting the website.

### Access the Portfolio

You can view my live portfolio website by visiting: [https://thuyein96.github.io/](https://www.google.com/search?q=https://thuyein96.github.io/)

### Repository Structure

  * `index.html`: The main HTML file for the website.
  * `css/`: Contains all CSS stylesheets.
  * `js/`: Contains all JavaScript files.
  * `images/`: Stores images used on the website.
  * Other files and directories as needed for specific projects or assets.

### How to Run Locally (for contributors or if you want to explore the code)

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/thuyein96/thuyein96.github.io.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd thuyein96.github.io
    ```
3.  **Open `index.html` in your web browser.**

4. **Open `thuyein96.github.io/petstore` to view petstore.**
